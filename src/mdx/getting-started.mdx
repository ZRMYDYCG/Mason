# 介绍

## 什么是 Mason

Mason 是面向中后台场景的前端解决方案，基于 Vue 3 与 TypeScript，提供常用管理端能力与可扩展的工程结构。

## 核心特性

- 目录分层清晰，便于协作与维护。
- 支持路由、菜单、权限与多种布局。
- 内置主题切换、国际化、状态持久化等常见能力。
- 文档使用 MDX，可在正文中嵌入 Vue 组件与示例。

## 适用场景

管理后台、数据看板、业务中台、运营系统，以及需要统一工程规范的团队项目。
