# 介绍

## 什么是 Mason ?

Mason 是一个现代化的中后台前端解决方案，基于 Vue3 + TypeScript 构建，提供开箱即用的功能模块与灵活的扩展能力，帮助开发者专注于业务实现。

## 核心特性

- 清晰的目录结构，适合长期维护与团队协作。
- 灵活的路由、菜单、权限和布局能力。
- 支持主题切换、国际化、状态持久化等常见中后台能力。
- 文档基于 MDX，可在文章中直接嵌入组件和交互示例。

## 适用场景

适用于管理后台、数据看板、业务中台、运营系统和需要快速沉淀工程规范的团队项目。
